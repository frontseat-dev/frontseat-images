# mise

[mise](https://mise.jdx.dev)'s own release binary, pinned by checksum per
architecture, for the runner. Wolfi does not package it yet
([wolfi-dev/os#78684](https://github.com/wolfi-dev/os/pull/78684)); when it
does, delete this directory and the runner takes Wolfi's.

A new version: its `version`, and both `expected-sha256` from the release's
`SHASUMS256.txt`.
