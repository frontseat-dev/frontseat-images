# nono

[nono](https://github.com/nolabs-ai/nono)'s own release binary, pinned by
checksum per architecture, for the runner: what confines each build action
to its own root, with no network unless it fetches, by Landlock and seccomp
and with no privilege. Wolfi does not package it.

A new version: its `version`, and both `expected-sha256` from the
release's archives; the licence's, from the release tag's `LICENSE`.
